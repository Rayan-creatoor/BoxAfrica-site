Box.Africa — version homepage modifiée

Fichiers :
- box-africa-home-updated.jsx : composant React mis à jour.
- boxafrica-logo-transparent.png : logo complet extrait de l'image fournie, fond transparent.
- boxafrica-box.png : symbole "boîte" extrait du logo, fond transparent.

Installation :
1. Placez les deux PNG dans le dossier public/ de votre projet React/Vite.
2. Remplacez l'ancien composant par box-africa-home-updated.jsx.
3. Vérifiez que la route /services existe pour les boutons "En savoir plus".
4. Les photos IT utilisent des URLs distantes Pexels ; pour une mise en production, vous pouvez les télécharger et les héberger localement.

Modifications principales :
- Hero avec photo en arrière-plan + overlay coloré.
- Suppression du logo hexagonal tournant du hero.
- Logo Box.Africa fourni utilisé dans la navbar et le footer.
- Compteurs animés déclenchés lorsque la section statistiques entre dans l'écran.
- Section photos avec de vrais professionnels noirs dans un contexte IT.
- Images circulaires dans THINK / POC / BUILD / RUN.
- Bouton "En savoir plus" sur chaque service vers /services.
- Symbole "boîte" extrait du logo animé dans "Un projet IT à transformer ?".
- Palette légèrement plus colorée et ajout d'une section claire pour éviter un rendu trop noir.
